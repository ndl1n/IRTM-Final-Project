# LawExplore 團隊手冊

直接跳到自己的角色：[A 資料與前端](#a-資料與前端)、[B 詞組索引](#b-詞組索引)、[C 搜尋與推薦](#c-搜尋與推薦)、[D 詞組關聯](#d-詞組關聯)、[E 評估與研究](#e-評估與研究)。每段都可以單獨貼給 AI，搭配段落裡列出的檔案一起討論。如果 AI 無法讀取專案資料夾，把相關檔案和任務說明一起提供給它。

## 大家先做的事

1. 按 [README](../README.md) 啟動網站，走一次「搜尋 → 讀原文 → 詞組探索」。執行 `python -X utf8 manage.py example A` 看例子，把 A 換成自己的代號。
2. 打開 [A.csv](../data/annotations/A.csv) 對照格式。B～E 的第一輪可以先從各自領域做 3 筆原文核對、5 個詞組、5 組口語對照、3 道搜尋題，以及每題對應的相關性標註。使用已收錄的文本和文件 ID。
3. 交檔前各自核對原文、詞組和題目對應的文件。把查核依據或疑問寫在 `evidence`。存成 UTF-8，保留 11 欄及欄位順序。用法見[技術參考](TECHNICAL.md#csv-怎麼填)。

目前網站的搜尋排序用 BM25，詞組探索逐份掃描文本。D 的共現證據已接到 API，前端可依技術參考的 `evidence=1` 串接。大家可以先用這些現有功能測試自己的模組。

## 怎麼找法條和補進網站

1. **先查專案裡有沒有。** 在 LawExplore 選領域，用關鍵字搜尋。若找到要用的條文，可在 `corpus.jsonl` 用法規名稱和條號找到 `doc_id`，再填進自己的 CSV。不同人可以引用同一個 `doc_id`。
2. **沒找到就查官方來源。** 到全國法規資料庫搜法規名稱或關鍵字，例如「勞動基準法」或「加班」，進到法規頁核對條號、全文、修正日期和生效註記。契約規範可以查主管機關的公告。 [全國法規資料庫](https://law.moj.gov.tw/)
3. **把缺的條文交給 A。** 傳「領域／法規名稱／第幾條或第幾點／官方連結／用途」，並附上查到的版本或生效資訊。A 檢查是否已收錄，再更新來源、重建搜尋資料，把可用的 `doc_id` 和 `corpus_id` 告訴大家。接著用這兩個 ID 填 CSV。 [A 的重建步驟](TECHNICAL.md#語料來源和更新)

## A 資料與前端

**改哪裡**　`frontend/index.html` 放頁面結構，`frontend/app.js` 接 API 和操作，`frontend/style.css` 管畫面。`data/annotations/A.csv` 放租賃標註，`src/corpus/parser.py` 在來源解析需要調整時才改。

**先做什麼**　確認 A.csv 的租賃原文、搜尋題和標註。前端先做一個能展示的改動：詞組探索頁顯示「點交 · 共同出現 4 份」這類共現數字，數字從 API 讀取。D 提供共同文件 ID 後，再讓使用者點開證據。B 的索引只要維持原本的回傳格式，既有次數和原文高亮就能繼續用。C 的推薦與 E 的研究事件規格完成後，再接到各自的畫面或操作。

**完成時交什麼**　交修改過的前端檔案、A.csv、兩三步可照做的展示方式。有更新來源時，附來源連結、版本和重建結果。驗收時要能從搜尋或詞組探索開到正確的原文。

**可以貼給 AI**

### 怎麼覆核 A 的租賃資料

A.csv 目前有 218 筆，其中 100 筆是租賃原文，另外有 19 個詞組、19 組口語對照、25 道搜尋題和 55 筆相關性標註。先篩 `audit`，打開 `source_url` 對照全文、條號、版本和生效日期。契約規範遇到跨頁時，接著核對下一頁。再看 `phrase` 和 `mapping` 能否在引用原文找到，最後將 `query` 的 ID 和 `qrel` 的 `query_id` 對起來。搜尋題可以先看修繕例子 `A_Q_09`，分別核對一般租賃、住宅租賃和契約規範怎麼描述修繕。差異記在 `evidence`。如果來源原文需要更新，由 A 更新來源再重建。

## 怎麼交回來

交自己改的檔案，沿用原目錄。附上用的基準版本、一句話說明改了什麼、怎麼重跑、看到什麼結果，以及待辦。共用正式版本可放 GitHub，每次由小組安排一位成員整合。

日常只需要動角色段落列的檔案。來源快照和 `corpus.jsonl` 由來源更新及重建流程處理。`src/services.py`、`src/api/server.py`、`config/`、啟動腳本、共用驗證器與 `tests/` 有改動需求時，先和會受影響的成員對一下。

合併後跑 `python manage.py check` 和 `python -m unittest discover -s tests -v`，再試走一次網站。需要重新發分享包時跑 `python manage.py package`。
